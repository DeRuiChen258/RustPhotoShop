# Assets

Everything the application needs besides its own code. The installer (`rustphotoshop --install`, or
`../packaging/install.sh`) copies these into `~/.local/share/icons` and
`~/.local/share/rustphotoshop/assets`, and the binary finds them from there or from this directory
while developing.

## `icons/hicolor/`

The application icon at the seven sizes the freedesktop icon theme expects, in the theme's own
layout (`<size>x<size>/apps/rustphotoshop.png`). The window icon, the taskbar icon, the launcher and
the Desktop shortcut all end up showing the same picture because they all resolve the same icon
name from this set.

The artwork is the image the project was asked to use,
`图标/30f8cfffc3d09087aa (Edited).png` at the repository root (2839×2839, sRGB). The sizes here are
Lanczos-resampled from it; `../scripts/make-icons.sh` regenerates them and is the only thing that
should ever write into this directory.

| Size | Used for |
|------|----------|
| 16 | window lists, tree views |
| 32 | small launchers |
| 48 | the application grid on most desktops |
| 64 | larger grid sizes |
| 128 | GNOME's overview at its largest zoom |
| 256 | file manager previews, the window icon |
| 512 | high-DPI launchers, the About dialog |

The icon is fully opaque, as the source artwork is: nothing here adds a mask or a background.

## `mime/`

`application-x-compositor-project.xml` teaches the desktop that a `.comp` file is a RustPhotoShop
project, so the file manager's "Open with" list offers the application for it.

## `rustphotoshop.desktop`

A reference copy of the desktop entry. The installed entry is generated by
`platform::desktop::desktop_entry` with the real binary path filled in, so this file exists to be
read and diffed, not to be copied verbatim.
