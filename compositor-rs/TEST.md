# 测试文档

测试分五层，从「像素算法对不对」一直到「双击桌面图标能不能开窗」。所有测试都可以在无显示
的环境里跑（界面测试用无头模式），只有最后的启动冒烟测试需要窗口系统。

## 一条命令跑完全部

```bash
./scripts/test.sh
```

它会依次执行：格式检查、静态检查（`-D warnings`）、全部单元与集成测试、发布构建、内置自检、
桌面启动项校验、启动冒烟测试，并把结果写进 [TEST-REPORT.md](TEST-REPORT.md)。任何一步失败
都会以非零状态退出。

### 3. 内置自检（`rustphotoshop --self-test`，13 项）

装在程序里，装到任何机器上都能立刻回答「这个构建能不能用」：

C 内核、抖动内核、抖动滤镜可用性、中文字体（含字形覆盖检查）、文档编辑、图层合成、
选区与内容感知填充、工程保存与打开、图像导入导出、Photoshop 导入、应用图标、桌面启动项、
用户目录可写。`--self-test-verbose` 会列出每一项的细节。

### 4. 启动冒烟测试

```bash
rustphotoshop --smoke-test 30 --smoke-report /tmp/smoke.txt
```

真的打开窗口、绘制 30 帧（其间会合成一张 800×600 的文档并上传纹理）、然后退出并把结果写进
报告文件。这是唯一需要显示环境的测试；`scripts/test.sh` 在无显示环境会自动跳过并标注。

### 5. 手工验证清单

自动化测试覆盖了算法、格式、安装与布局，但鼠标手势与视觉效果需要人工确认一次：

1. 双击桌面上的 **RustPhotoShop** 图标 → 窗口打开，界面是中文，标题栏显示 `未命名 — RustPhotoShop`。
2. 「文件 ▸ 新建」创建一个文档 → 画布出现白色背景与棋盘格外的深灰底。
3. 用画笔在画布上拖动 → 出现笔迹；按 `Ctrl+Z` 撤销、`Ctrl+Shift+Z` 重做。
4. 「文件 ▸ 打开」任一 PNG/JPEG → 图像显示；拖动工具条上的矩形选框 → 出现选区高亮。
5. 「调整 ▸ 色相/饱和度…」拖动滑块 → 画布实时变化；「取消」恢复原状。
6. 「图层」面板新建图层、改混合模式与不透明度 → 画面随之变化。
7. 「文件 ▸ 保存」存成 `.comp` → 关闭再打开，画面与图层结构一致。
8. 「文件 ▸ 导出…」导出 PNG → 用图片查看器确认透明通道与内容正确。
9. 关闭窗口 → 进程退出（`ps -ef | grep rustphotoshop` 无残留），日志写到
   `~/.local/state/rustphotoshop/rustphotoshop.log`。
10. 拖一个图片文件到窗口里 → 作为新图层导入。

## 无法自动化的部分（本机限制）

本机的 GNOME 拒绝截图 D-Bus 调用，也没有安装 Xvfb 等虚拟显示，因此**没有做逐像素的视觉
验收**：界面正确性由「无头布局测试 + 开窗冒烟测试 + 人工清单」三件套保证。同样地，真实
鼠标拖拽的手感需要人工体验一次（算子本身有单元测试）。

## 复现测试的最低要求

- Rust 1.95+（测试代码用到了 `std::sync::Mutex` 常量初始化等现代特性）
- `sha256sum`（内核一致性校验）
- 可选：`desktop-file-validate`（桌面项规范校验，缺失时该断言自动跳过）
- 可选：`clang` + Blocks 运行时（否则抖动内核相关的检查会标记为 note 而非失败）
